# Courses suivies

Carnet de prix pour les courses. Tu notes un montant au magasin, puis tu vois ce qui augmente, ce qui reste stable, et une alternative moins chère déjà présente dans le même rayon.

Les données restent dans le navigateur (IndexedDB).

## Lancer

```sh
npm install
npm run dev
```

## Vérifier

```sh
npm run test:unit -- --run
npm run lint
npm run build
```

## Stack

Vue 3, Vite, JavaScript, Vue Router, Pinia, Tailwind CSS, VueUse, Chart.js, Vitest.
